# Herramientas STEPBible

Estos scripts procesan fuentes públicas fijadas a commits específicos y generan artefactos verificables antes de cualquier importación a Supabase.

- `extract_nt_corpus.py`: extrae y valida los 27 libros del Nuevo Testamento desde TAGNT.

Los scripts no escriben en Supabase ni modifican producción.
