# FASE D · Bloque 4 — Corpus contextual de poesía y sabiduría

Fecha: 2026-08-02

## Objetivo

Extender Estudio Profundo a los principales libros poéticos y sapienciales mediante contenido editorial interno, diferenciando poesía, máxima general, debate sapiencial y reflexión espiritual.

## Criterios editoriales

### Job

- el sufrimiento no demuestra automáticamente culpa;
- las voces de Job, sus amigos, Elihú y Dios se distinguen;
- la restauración final no se presenta como fórmula de recompensa material;
- se protege a la persona que sufre frente a explicaciones pastorales simplistas.

### Salmos

- se conserva la división interna en cinco libros;
- se identifican lamento, alabanza, confianza, realeza, sabiduría y peregrinación;
- los títulos y atribuciones se tratan como tradiciones antiguas, no como fecha segura;
- las metáforas no se leen literalmente;
- los salmos imprecatorios no autorizan venganza o violencia.

### Proverbios

- las máximas describen patrones generales, no garantías automáticas;
- pobreza, riqueza, crianza y salud no se reducen a una sola causa;
- los dichos se interpretan según situación y colección;
- Proverbios 31 no se usa para promover sobrecarga, comparación corporal o un único ideal social femenino.

### Eclesiastés

- `hebel` se explica como vapor, transitoriedad, enigma o frustración según contexto;
- el libro no se presenta como nihilista;
- el gozo se entiende como recepción responsable de bienes limitados;
- reconocer estaciones no equivale a justificar abuso o tragedia.

### Cantares

- se presenta primero como poesía de amor humano;
- las lecturas judías, cristianas y místicas se identifican como capas posteriores;
- se priorizan reciprocidad, respeto, paciencia y dignidad;
- las metáforas no se convierten en estándares corporales;
- no se incluye contenido explícito ni se utiliza el libro para justificar presión, posesión o conductas peligrosas.
