# ADR-001 — Biblia como referencia visual

Estado: ACEPTADA

Fecha: 2026-07-26

## Contexto

La experiencia de Biblia alcanzó una combinación aprobada de minimalismo, navegación clara, botones circulares y temas visuales.

## Decisión

Usar Biblia como referencia para futuros experimentos del sistema visual global.

## Consecuencias

- No se copiarán estilos directamente a producción.
- Los patrones deberán extraerse como componentes reutilizables.
- Toda adopción global se probará primero en laboratorio.
- Biblia queda protegida contra cambios transversales no validados.
