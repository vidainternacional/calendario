# ADR-002 — Tres temas visuales

Estado: ACEPTADA PARA EXPERIMENTACIÓN GLOBAL

Fecha: 2026-07-26

## Contexto

Biblia utiliza los temas claro, sepia y oscuro con una experiencia aprobada.

## Decisión

Conservar esos tres temas como estándar candidato para la aplicación completa.

## Consecuencias

- Su uso global no se considera implementado todavía.
- Deben definirse tokens semánticos, contraste y comportamiento de componentes.
- La primera implementación será aislada y reversible.
- No se alterará el tema actual de toda la aplicación sin validación del propietario del producto.
