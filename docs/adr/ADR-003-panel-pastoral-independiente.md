# ADR-003 — Panel Pastoral como área especializada

Estado: ACEPTADA

Fecha: 2026-07-26

## Contexto

El Panel Pastoral reúne herramientas ministeriales distintas de la administración técnica general.

## Decisión

Mantener el Panel Pastoral como área especializada, con acceso y navegación acordes al rol pastoral, sin mezclarlo innecesariamente con el panel administrativo.

## Consecuencias

- Los permisos deben comprobarse en servidor y cliente según corresponda.
- Las herramientas pastorales deben conservar una experiencia coherente entre sí.
- El cierre de Fase C requiere validar la navegación interna y los enlaces publicados.
- Las futuras mejoras visuales no deben debilitar la separación de responsabilidades.
