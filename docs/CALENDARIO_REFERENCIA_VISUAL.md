# Calendario — referencia visual aprobada

Fecha: 2026-08-04

La referencia aprobada por el usuario es la estructura del calendario nativo de iPhone, adaptada al lenguaje visual de VIDA Internacional.

## Requisitos confirmados

- El calendario ocupa la pantalla completa y llega visualmente hasta los bordes seguros.
- No debe parecer un módulo externo dentro de una tarjeta grande.
- Vista mensual, semanal y agenda deben sentirse como superficies nativas.
- Diseño minimalista, elegante, limpio y con alta densidad útil.
- Controles compactos para Hoy, periodo, búsqueda futura, creación y cambio de vista.
- Indicadores discretos de eventos mediante puntos o barras.
- Lista o detalle del día seleccionado como continuación natural del calendario.
- Modo claro actual; modo nocturno se implementará posteriormente de forma global.
- El mismo criterio de integración aplica al panel pastoral, Biblia y cualquier contenido añadido dentro de la app.

Las capturas proporcionadas por el usuario son la guía de estructura y proporción, no una obligación de copiar el color negro del modo oscuro.
