# Decisiones Aprobadas

Estado: VIGENTE

Este documento registra únicamente decisiones aprobadas explícitamente por el propietario del producto. No deben reinterpretarse ni sustituirse sin una nueva aprobación.

## DA-001 — Biblia como referencia visual

Se adopta la experiencia visual de la Biblia como referencia principal para futuras pruebas del sistema visual global.

Elementos aprobados:

- diseño minimalista;
- botones circulares;
- iconografía limpia;
- distribución clara;
- navegación sencilla;
- sensación de aplicación móvil nativa.

## DA-002 — Tres temas

Los temas claro, sepia y oscuro quedan aprobados como base para futuras pruebas de diseño global.

Su expansión fuera de Biblia deberá probarse primero en laboratorio.

## DA-003 — Protección de la aplicación estable

No se harán rediseños globales directamente sobre producción.

Flujo obligatorio:

Baseline → Laboratorio → Validación → Producción

## DA-004 — Memoria oficial en GitHub

GitHub es la fuente oficial de memoria técnica, visual, histórica y arquitectónica del proyecto.

Los chats no sustituyen la documentación versionada.

## DA-005 — Componentes estables

Los componentes aprobados no se modifican de forma transversal sin una prueba aislada, evidencia y posibilidad de rollback.

## DA-006 — Fases del proyecto

La fase activa se determina exclusivamente mediante `VIDA_INTERNACIONAL.md` y su documento de fase correspondiente.

No se avanza a la siguiente fase hasta que el documento maestro confirme el cierre de la actual.

## DA-007 — Baselines versionadas

Se conservarán líneas base por hitos importantes:

- Baseline 1.0: estado estable previo al cierre formal de Fase C;
- Baseline 1.1: estado validado después del cierre de Fase C;
- Baseline 2.0: futura consolidación del sistema visual global y fases posteriores.
