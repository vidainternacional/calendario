# Visión del Producto

Vida Internacional no es únicamente un calendario.

Es un ecosistema digital para servir, organizar y acompañar a la iglesia.

## Principios de producto

- Toda nueva función debe integrarse con el sistema existente.
- No deben duplicarse tareas ni flujos.
- Ningún módulo debe sentirse externo.
- La aplicación debe crecer sin perder simplicidad.
- La tecnología debe reducir carga administrativa y fortalecer el cuidado de las personas.
- La experiencia debe sentirse coherente, humana y espiritual.

## Dirección visual

La aplicación debe evolucionar hacia una identidad común inspirada en las fortalezas ya aprobadas de Biblia:

- minimalismo;
- claridad;
- controles táctiles reconocibles;
- botones circulares cuando sean apropiados;
- temas claro, sepia y oscuro;
- sensación de producto móvil nativo.

Esta dirección se explorará sin reemplazar directamente la interfaz estable.

## Criterio de pertenencia

Antes de agregar una función debe responderse:

1. ¿Ayuda a cuidar mejor a la iglesia?
2. ¿Evita trabajo repetitivo?
3. ¿Pertenece naturalmente al sistema?
4. ¿Puede utilizarse de manera sencilla en un celular?
5. ¿Mantiene la privacidad y los permisos?

Si no cumple estos criterios, debe replantearse.
