# NO ROMPER ESTO

Estado: ADVERTENCIA OBLIGATORIA

Leer antes de modificar componentes compartidos, estilos globales, permisos, navegación o Biblia.

## Biblia

No tocar directamente:

- botones y menú circular;
- temas claro, sepia y oscuro;
- selector y navegación de lectura;
- favoritos;
- notas;
- persistencia;
- experiencia móvil aprobada.

Primero: laboratorio, comparación, validación y aprobación.

## Autenticación

No tocar sin probar sesión, redirecciones y rutas protegidas.

## Permisos y seguridad

No mover validaciones sensibles exclusivamente al cliente.
No ampliar acceso para resolver temporalmente un error.
No modificar políticas sin revisar cada rol afectado.

## Navegación inferior

No cambiar rutas, orden o estado activo sin pruebas completas en móvil.

## Panel Pastoral

Mientras la Fase C siga activa:

- no realizar refactorizaciones generales;
- no rediseñar transversalmente;
- no alterar permisos para acelerar pruebas;
- no cerrar la fase sin evidencia visual final.

## Estilos globales

No agregar reglas genéricas para arreglar una sola pantalla.
No usar selectores amplios sin revisar todas las rutas alcanzadas.
No convertir una prueba visual en producción por defecto.

## Regla final

Una mejora que rompe otra función no es una mejora. Ante duda, conservar el comportamiento estable y aislar el experimento.
