# Checklist de Regresión

Estado: OBLIGATORIO

## Antes de cambiar

- [ ] Confirmar fase activa.
- [ ] Leer memoria técnica y decisiones aprobadas.
- [ ] Identificar componentes protegidos afectados.
- [ ] Registrar commit o referencia estable de retorno.
- [ ] Limitar el cambio al alcance necesario.

## Validación general

- [ ] La aplicación compila.
- [ ] El despliegue termina correctamente.
- [ ] No aparecen errores nuevos en consola.
- [ ] No hay desbordamiento horizontal inesperado.
- [ ] Carga, vacío y error tienen una presentación utilizable.
- [ ] Funciona en móvil y escritorio.
- [ ] Los controles táctiles son accesibles.

## Autenticación y navegación

- [ ] Inicio de sesión.
- [ ] Cierre de sesión.
- [ ] Persistencia de sesión.
- [ ] Rutas protegidas.
- [ ] Navegación inferior.
- [ ] Estado activo y botón Atrás.

## Biblia

- [ ] Apertura inicial.
- [ ] Cambio de libro y capítulo.
- [ ] Navegación anterior/siguiente.
- [ ] Temas claro, sepia y oscuro.
- [ ] Favoritos.
- [ ] Notas.
- [ ] Menú y botones circulares.
- [ ] Sin parpadeos o bloqueos visuales nuevos.

## Panel Pastoral

- [ ] Acceso correcto por rol.
- [ ] Colecciones de versículos.
- [ ] Bosquejos y modos de presentación.
- [ ] Biblioteca y apertura de recursos.
- [ ] Materiales de estudio.
- [ ] Publicación y apertura desde Inicio.
- [ ] Enlaces internos permanecen dentro de la aplicación.

## Datos y seguridad

- [ ] Permisos del servidor siguen vigentes.
- [ ] No se expone información de otros roles.
- [ ] Crear, editar y eliminar afectan solo los datos esperados.
- [ ] No se introducen operaciones destructivas sin confirmación.

## Cierre

- [ ] Evidencia registrada.
- [ ] Memoria o regresiones actualizadas.
- [ ] Changelog actualizado.
- [ ] Commit descriptivo.
- [ ] Documento de fase actualizado cuando corresponda.
