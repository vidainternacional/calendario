# Reglas operativas explícitas del usuario

Estas reglas complementan el documento maestro del proyecto y deben respetarse en cualquier conversación futura de VIDA Internacional.

1. **No generar imágenes mediante IA salvo solicitud explícita del usuario.**
   - Si el usuario adjunta una captura, fotografía o referencia visual, debe analizarse como evidencia del estado real de la interfaz.
   - No crear una imagen nueva, mockup, rediseño generado ni referencia visual por iniciativa propia.
   - Si el usuario pide modificar la aplicación a partir de una captura, aplicar el cambio directamente en el código y validar el resultado.

2. Ejecutar solamente los cambios solicitados dentro de la fase y bloque activos, conservando las decisiones ya aprobadas.
